# Khushaank Gupta

Personal website for Khushaank Gupta, focused on AI, business, finance, and systems.

The site includes Khushaank, a calm interactive companion that greets visitors, stays still while idle, reacts to clicks, and occasionally runs to the opposite corner after a longer period of inactivity.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Validate a production build with `npm test`.
