# Khushaank Gupta

Personal website for Khushaank Gupta, focused on AI, business, finance, and systems.

The site includes Khushaank, an interactive animated companion that roams the viewport, follows the pointer, and reacts to scrolling, hovering, and clicks.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Validate a production build with `npm test`.
